# WebSeal 使用示例

本文档提供 WebSeal 的详细使用示例和最佳实践。

## 📋 基础使用流程

### 1. 网页快照生成

#### 示例场景：保存电商商品页面

```
目标网址: https://example-shop.com/product/123
自定义文字: 存档编号-2025-0615-001 | 原价 ¥299
```

**操作步骤：**

1. 打开 WebSeal 应用
2. 选择"网页截图与水印"标签
3. 输入目标网址：`https://example-shop.com/product/123`
4. 输入自定义文字：`存档编号-2025-0615-001 | 原价 ¥299`
5. 点击"生成水印快照"
6. 等待 10-30 秒完成截图
7. 预览结果并下载保存

**生成的文件名示例：**
```
webseal-example-shop-com-2025-06-15-14-30-25.png
```

#### 示例场景：保存新闻报道

```
目标网址: https://news.example.com/article/important-news
自定义文字: 新华社报道 | 存档时间: 2025-06-15
```

### 2. 水印提取验证

#### 验证之前保存的截图

1. 切换到"水印提取验证"标签
2. 上传之前保存的截图文件
3. 系统自动提取水印信息
4. 验证显示的信息是否正确

**提取结果示例：**
```json
{
  "timestamp": "2025-06-15T14:30:25.123Z",
  "customText": "存档编号-2025-0615-001 | 原价 ¥299",
  "url": "https://example-shop.com/product/123"
}
```

## 🎯 使用场景详解

### 内容留痕场景

#### 1. 电商页面留档

**背景：** 商品页面会随活动调价或下架，需要留存某个时点的页面状态。

**操作建议：**
- 自定义文字包含：商品编号、原价、促销信息
- 在价格变动前后各留存一份，便于对比
- 保存完整的商品详情页面

**示例：**
```
网址: https://shop.example.com/item/12345
自定义文字: 商品编号ABC123 | 原价¥199 | 促销价¥99
```

#### 2. 在线条款变更记录

**背景：** 在线条款、规则或说明文档会被更新，需要留存历史版本。

**操作建议：**
- 截图包含完整的条款正文
- 自定义文字记录条款编号和版本信息
- 定期留存，形成变更时间线

**示例：**
```
网址: https://docs.example.com/terms/456789
自定义文字: 条款编号CT2025001 | 版本v2 | 更新日期：2025-06-15
```

#### 3. 原创内容留痕

**背景：** 需要记录原创内容在某一时刻的发布状态。

**操作建议：**
- 在自定义文字中标注内容来源与作者
- 截图时确保内容区域完整可见
- 相关页面一并留存，形成完整的时间线

**示例：**
```
网址: https://blog.example.com/posts/original-article
自定义文字: 原创作者：XXX | 发布时间：2025-06-15 | 内容类型：图文
```

### 网页归档场景


## 🔧 高级使用技巧

### 1. 批量留痕策略

当需要保存多个相关页面时：

1. **制定编号规则**
   ```
   存档001: 主页快照
   存档002: 产品页快照  
   存档003: 价格页快照
   存档004: 条款页快照
   ```

2. **保持时间连续性**
   - 在短时间内完成所有截图
   - 确保时间戳能够形成完整的时间线

3. **文件命名规范**
   ```
   项目名称-页面类型-序号-日期时间.png
   例：电商页面-商品页-001-20250615.png
   ```

### 2. 水印信息优化

#### 自定义文字最佳实践

1. **包含关键信息**
   ```
   存档编号 | 相关方 | 关键金额 | 重要日期
   ```

2. **使用分隔符**
   ```
   使用 | 或 - 分隔不同信息段
   避免使用特殊字符影响提取
   ```

3. **控制长度**
   ```
   建议总长度不超过200字符
   过长可能影响水印质量
   ```

### 3. 质量保证措施

#### 截图前检查

1. **确认页面完全加载**
   - 等待图片加载完成
   - 确认动态内容显示正常
   - 检查页面滚动完整性

2. **网络环境**
   - 使用稳定的网络连接
   - 避免高峰期操作
   - 重要页面建议多次截图对比

3. **浏览器兼容性**
   - 使用主流浏览器访问
   - 关闭广告拦截器
   - 确认页面显示正常

#### 存储和管理

1. **文件组织**
   ```
   归档文件夹/
   ├── 原始截图/
   │   ├── webseal-存档001-20250615.png
   │   └── webseal-存档002-20250615.png
   ├── 水印提取结果/
   │   ├── 存档001-水印信息.json
   │   └── 存档002-水印信息.json
   └── 说明文档/
       └── 存档清单.md
   ```

2. **备份策略**
   - 多个存储位置备份
   - 云存储和本地双重保存
   - 定期验证文件完整性

## 📊 常见问题解决

### 截图问题

#### Q: 截图不完整或缺少内容

**原因分析：**
- 页面加载时间不够
- 动态内容未完全渲染
- 页面存在懒加载元素

**解决方案：**
1. 稍等片刻后重新截图
2. 手动滚动页面确保内容加载
3. 检查页面是否有反爬虫机制

#### Q: 截图质量不清晰

**原因分析：**
- 网络环境不稳定
- 目标页面分辨率问题
- 系统资源不足

**解决方案：**
1. 确保网络稳定
2. 尝试在不同时间段操作
3. 刷新页面后重新截图

### 水印问题

#### Q: 水印提取失败

**原因分析：**
- 图片经过压缩或转换
- 文件格式不兼容
- 图片损坏或不完整

**解决方案：**
1. 使用原始未处理的图片
2. 确保文件格式为 PNG/JPG
3. 检查文件是否完整

#### Q: 提取的信息不正确

**原因分析：**
- 图片被恶意篡改
- 水印数据损坏
- 非 WebSeal 生成的图片

**解决方案：**
1. 对比原始文件
2. 检查文件来源
3. 重新生成快照

## 🚀 最佳实践总结

### Do's (推荐做法)

1. ✅ **及时保存**：发现重要页面立即截图
2. ✅ **详细记录**：在自定义文字中包含关键信息  
3. ✅ **多重备份**：保存多个副本在不同位置
4. ✅ **定期验证**：定期检查水印提取功能
5. ✅ **规范命名**：使用有意义的文件名
6. ✅ **完整页面**：确保截图包含完整信息

### Don'ts (避免做法)

1. ❌ **延迟保存**：不要等到争议发生才截图
2. ❌ **信息不足**：避免自定义文字过于简单
3. ❌ **单一备份**：不要只保存一个副本
4. ❌ **格式转换**：避免对截图进行压缩或格式转换
5. ❌ **忽略验证**：不要忘记验证水印提取功能
6. ❌ **随意命名**：避免使用无意义的文件名
